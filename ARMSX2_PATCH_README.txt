NeoStation iOS — ARMSX2 library sync/deeplink patch
===================================================

Base: the -neostation-ios.zip project supplied in the ChatGPT conversation.

Installation
------------
1. Close any editor that could rewrite these files automatically.
2. Extract this archive.
3. Copy the CONTENTS of this folder into the root of your NeoStation repository.
4. Accept replacement/merge of the existing files.
5. In GitHub Desktop, verify the changed-files list before committing.
6. Commit + Push, then run the iOS GitHub Actions workflow and install the IPA.

What this patch does
--------------------
- Adds Sync / Re-sync to the ARMSX2 card, like RetroArch.
- Requests ARMSX2's exported library through its iOS deeplink protocol.
- Receives neostation://armsx2?...&payload=... through the existing native URL listener.
- Caches the exported ARMSX2 game list and rescans NeoStation after sync.
- Matches PS2 ROM filenames against the ARMSX2 export.
- Launches matching PS2 games directly with ARMSX2's exported launchURL.
- Keeps the existing RetroArch / Open In / Share Sheet paths as fallbacks.
- Adds armsx2 to LSApplicationQueriesSchemes in both iOS CI configurations.

First device test
-----------------
1. Settings > Directories > ARMSX2: link the ARMSX2 game folder if not already linked.
2. Tap Sync.
3. ARMSX2 should open, export its library, then return automatically to NeoStation.
4. Wait for NeoStation's rescan to finish and check the PS2 library.
5. Launch one synced PS2 game. ARMSX2 should open directly without the share menu.

Diagnostics
-----------
If sync or direct launch does not work, check Files > On My iPhone > NeoStation for:
- armsx2_sync_debug.txt
- armsx2_launch_debug.txt
These are intentionally generated by the patch for on-device troubleshooting.
